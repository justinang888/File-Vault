Continuous Integration
- starts with developers, pushing to GitLab (only accessible within Amdocs network)
- then triggers job with Jenkins
- SonarQube - static code analysis
- Nexus - repository manager centralizing artifact management, streamlining dependency caching
- Jenkins - automation server, automating building, testing, deploying
